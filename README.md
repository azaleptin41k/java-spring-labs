# API для Спортивного Турнира

Это учебный проект, представляющий собой RESTful API для управления спортивным турниром. Сервис реализован на Spring Boot с использованием PostgreSQL в качестве базы данных.

## 🚀 Технологический стек

- Java 17+
- Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- Maven
- Git / GitHub

---

## Тема: спортивный турнир


### Основные сущности:
Для реализации предметной области используются следующие JPA-сущности:

*   **Team:** Спортивная команда (содержит ID, название, город).
*   **Player:** Игрок, принадлежащий к определенной команде (содержит ID, имя, позицию и ссылку на команду).
*   **Venue:** Место проведения матча или стадион (содержит ID, название, город, вместимость).
*   **Match:** Матч между двумя командами на определенной площадке (содержит ID, ссылки на две команды и место проведения, дату/время и результат).

## Какие операции умеет выполнять сервис?

Сервис поддерживает полный набор **CRUD-операций** (Создание, Чтение, Обновление, Удаление) для всех перечисленных выше сущностей через соответствующие эндпоинты (`/api/teams`, `/api/players`, `/api/venues`, `/api/matches`).

### Бизнес-операции

Помимо базовых CRUD-операций, сервис умеет выполнять следующие бизнес-задачи:

1.  **Получение состава команды:** Получить список всех игроков, принадлежащих к определенной команде.
2.  **Планирование матча с валидацией:** При создании матча выполняется проверка, что команда не может играть сама с собой.
3.  **Запись результата матча:** Обновление информации о матче для добавления итогового счета.
4.  **Трансфер игрока:** Перевод игрока из одной команды в другую в рамках одной транзакции.
5.  **Получение списка будущих матчей:** Выборка только тех матчей, которые еще не состоялись.

## 🚀 Как запустить локально

#### 1. Предварительные требования
- Установленный JDK 17 или выше.
- Установленный Apache Maven.
- Установленный и запущенный сервер PostgreSQL.

#### 2. Настройка
1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/azaleptin41k/java-spring-labs.git
    cd java-spring-labs
    ```

2.  **Создайте базу данных:**
    - С помощью `pgAdmin` или любой другой утилиты создайте новую базу данных с именем `tournament_db`.

3.  **Установите переменную окружения:**
    - В вашей среде разработки (например, в IntelliJ IDEA в `Run/Debug Configurations`) установите переменную окружения `DB_PASSWORD`, присвоив ей пароль от вашего пользователя PostgreSQL.

#### 3. Запуск
- **Запустите приложение с помощью Maven:**
    ```bash
    mvn spring-boot:run
    ```
- При первом запуске Hibernate автоматически создаст все необходимые таблицы в базе данных.

После запуска приложение будет доступно по адресу `http://localhost:8080`. Для тестирования API используйте приложенную коллекцию Postman `Tournament-API.postman_collection.json`.
